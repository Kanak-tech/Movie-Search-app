# Movie Search App

A simple web app to search movies by name. It shows the poster, title and year of each result. Built with HTML, CSS and JavaScript using the OMDb API.

## Features
- Search movies by title
- Shows poster, title and year
- Shows a message while loading, and when no movie is found
- Placeholder image for movies without a poster

## Tech Used
- HTML
- CSS
- JavaScript (fetch API, async/await)
- [OMDb API](https://www.omdbapi.com/)

## How to Run
1. Download or clone this project.
2. Get a free API key from https://www.omdbapi.com/apikey.aspx
3. Open `script.js` and replace `YOUR_API_KEY_HERE` with your key.
4. Open `index.html` in your browser.
5. Type a movie name and click Search.
